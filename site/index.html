NYC 311 live pipeline

A pipeline on live New York City open data. Each morning it fetches only the requests that changed, updates a 90-day window and republishes, with no server to run.

  • About 960,000 requests kept current every day
  • Tests for duplicates, missing days, unusual volume and stale data
  • Runs free on GitHub Actions, with a log of every run
