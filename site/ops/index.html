NYC 311 live pipeline

Every morning at 06:15 UTC, GitHub Actions fetches only the New York City service requests that changed since the last run, updates a 90-day window, rebuilds the models, runs the tests and republishes this page. No server, no manual step.

How it's built

Free to run on GitHub Actions and GitHub Pages

StepToolWhat it does
ExtractPython, NYC Open Data APIFetches only requests changed since the last high-water mark, one day at a time, six days in parallel
LoadDuckDBUpserts by request ID into a rolling 90-day window, so a request closed days later is updated, not missed; state kept as Parquet between runs
Transform + testdbtModels, unique keys, no empty days, a volume check against the 28-day median, and source freshness
PublishGitHub PagesOnly when every dbt test passes; otherwise yesterday's page stays up and the state is not overwritten. A stale source is flagged on the page, not hidden

Data: NYC 311 Service Requests, NYC Open Data. Not affiliated with the City of New York. · Source code
