NYC 311: a pipeline that refreshes itself every morning

Every day at 06:15 UTC, GitHub Actions pulls only the New York City service requests that changed since the last run. It updates a 90-day window, rebuilds the models, runs the tests and republishes this page. There's no server and no manual step, and a request that gets closed days later is updated, not missed.
