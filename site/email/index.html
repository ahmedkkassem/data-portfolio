      Runs inside the same daily pipeline

      StepToolWhat it does
      Factsdbt martsLast week, the week before and the same week last year, plus product, country and day movers, written to one JSON file
      WriteClaude APIWrites the summary from the facts file only, under rules: no estimates, no causes it can't see in the data. With live data it runs each Monday; here the week never changes, so it ran once
      VerifyNumber guard (Python)Pulls every amount, percentage, count and point change out of the text and matches each one to a fact; one miss fails the build
      SendSchedulerFor a client: email or Slack at 07:00 on Monday, only after the guard passes. This demo publishes this page instead of sending
