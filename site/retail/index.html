How it's built

Rebuilt by GitHub Actions every morning at 06:15 UTC, at no cost

StepToolWhat it does
ExtractPythonDownloads the workbook (2 sheets, 1,067,371 rows) and lands every row untouched as Parquet, with a SHA-256 manifest
Transformdbt on DuckDBStaging, intermediate and mart models; every excluded row gets exactly one reason
Testdbt testsUnique keys, no nulls, valid values, sign rules, no gaps in the week calendar, totals that tie to the raw file
ReconcilepandasRe-implements the rules separately and must match the warehouse to the penny, or the build fails
PublishGitHub PagesSmall JSON files feed this page; a failed check stops the deploy, so yesterday's page stays up

For a client, the same models run on BigQuery fed from Shopify, Stripe, GA4 or ad accounts, and the dashboard can be Looker Studio. The tests and the reconciliation carry over unchanged.
